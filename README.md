# Геометрия 7 класс — тесты и задачи

Тренажёр по главе 1 учебника Атанасяна «Геометрия 7» — «Простейшие геометрические фигуры и их свойства».

- 1200 тестовых вопросов, по 200 на каждый параграф (§1–§6)
- 600 задач с вводом ответа, подсказками, пошаговым решением и чертежами, по 100 на параграф
- ключ ответов с поиском, работа над ошибками, оценка по результату

Работает в браузере без установки: откройте `index.html` или страницу GitHub Pages.

## Сборка

```
python src/build.py
```

`src/gen.py` создаёт тестовые вопросы, `src/tasks_fig.py` — задачи с чертежами, `src/template.html` — оформление страницы.
